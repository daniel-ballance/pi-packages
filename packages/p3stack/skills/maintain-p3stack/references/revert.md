# Verify the PR before reverting

Use the **repository root**. Accept a positive PR number, not an arbitrary URL, branch, SHA or title.

1. Resolve the intended GitHub owner/name and host from `git remote get-url origin`. Request `gh api repos/<owner>/<name>/pulls/<number>` on that host. Require matching number, `base.repo.full_name` equal to that owner/name, `base.ref` equal to main, `merged` true and a merge commit SHA. Fetch origin and require `git merge-base --is-ancestor <merge-sha> origin/main`. Require a single-parent squash commit, the shape landed by this procedure.
2. Inspect `git diff --raw <merge-sha>^ <merge-sha>` and the complete changed paths. Require a gitlink move for one manifest checkout under `packages/p3stack/vendor/`. Read the PR's added note under `packages/p3stack/docs/bumps/` **at the merge commit**. Match its old/new pins to that actual gitlink delta, and its sources to every manifest source sharing the checkout. Check every other path is a generated output, pin metadata or scoped maintenance repair accounted for by the note. A maintenance-looking branch or title is not evidence. Missing note, unrelated path, ambiguous repository or any other unclear provenance: **stop**, report blocked, and change nothing.
3. From current `origin/main`, use a clean isolated branch `revert/p3stack-<number>`. Run `git revert --no-edit <merge-sha>`, then `git submodule update --init --recursive`. On conflict abort the revert and report the conflicting paths; do not revert later work.
4. Run `./scripts/check.sh` and the [loader and smoke](references/smoke.md). Require green before pushing with hooks. Open a ready PR titled `revert(p3stack): <original subject>`; cite the original PR and candidate SHA, reason, failing command/output when applicable, and durable evidence.
5. Follow [landing](references/land.md) with no superseded PRs and no further revert. Only after green post-merge verification, comment on the original with the revert PR and report both URLs and commits. A failed revert or red main afterwards is blocked.
