# Practical model experience

Keep observations separate from interpretations. A benchmark refresh reads this record; it does not overwrite it. Store private task details, logs and measurements in a private run directory and refer to them here only with permission.

## Initial heuristic — 2026-09-27

User-reported experience, not a controlled evaluation: when a model at `xhigh` is insufficient, moving up a model tier and down to `high` can be a better escalation than using `max`. The benchmark exploration found exceptions, so the refresh process explicitly compares both directions rather than enforcing the heuristic.

No controlled Pi trials have yet been recorded for the proposed seven-option menu. Proposed role descriptions remain provisional.

Repeated evidence can narrow or expand a model's role, remove a frustrating intermediate escalation, or justify a provider-specific exception. Separate model behavior from adapter/provider failures. Trials that call models need an agreed budget and authorization; this record itself launches nothing.
